# תיקוני QA — הגשה אוטומטית ומקורות — 16.09.2026

התיקונים נמצאים בעץ העבודה המקומי. לא בוצעו commit, push או פריסה, לא שונו נתוני ייצור ולא הוגשו מועמדויות אמיתיות. אין בדוח הזה אישור שכל שירות חיצוני עובד מקצה לקצה.

## הגשה אוטומטית ובדיקה מונחית

- לחיצה חוזרת על הכנסת אותה הגשה לתור אינה מפעילה worker נוסף. החלפת מסלול של משימת ענן שכבר ממתינה דרך כפתור הכנסה לתור נחסמת. הכנסת הגשה פעילה או ממתינה לאימות מחדש לתור נחסמת.
- מצב שכבר אומת כ״נשלח״ אינו נדרס על ידי דיווח מאוחר מהסוכן. דיווח עם מזהה ניסיון ישן/זר אינו משנה ניסיון חדש.
- פתיחת בדיקה מונחית בזמן שסוכן רגיל כבר רץ מחזירה הודעה ברורה. בדיקה מונחית עם חלון תקף מתחברת לחלון הקיים.
- ״פתח בדיקה מונחית״ מטפל בחסימת חלון קופץ לפני הפעלת worker; סגירת החלון מפסיקה את בדיקות הסטטוס; שגיאת API מוצגת בחלון. כשל ברענון לוח הבקרה אינו מונע את פתיחת הסוכן.
- תוקן מבנה בקשת Browserbase: `timeout` בשורש, והוסרה בקשת `keepAlive` שהייתה תלויה בתוכנית השירות. גם כשל בחיבור CDP/פרסום כתובת הצפייה מדווח כהפעלת דפדפן שנכשלה. ההגדרה תואמת את [תיעוד יצירת הסשן](https://docs.browserbase.com/reference/api/create-a-session).
- ״הפעל מחדש את כולן״ כולל רק הגשות אוטומטיות שנכשלו ללא חסימה פתוחה; שאלות למשתמש, בדיקות מונחות והגשות שטרם אומתו אינן נשלחות מחדש בקבוצה. ה־API מחזיר את מצב ההפעלה שהסינון זקוק לו. הכפתור משתחרר גם אם רענון לוח הבקרה נכשל.
- כפתורי הגשה מחדש משתמשים במסלול המתאים: אוטומטי או מונחה. הגשה פעילה אינה מציגה ניסיון חוזר, והסרה בזמן פעילות אינה זמינה. תוקן גם ניסוח גיליון ציונים שהבטיח המשך אוטומטי ללא פעולה.
- קריאות התור ואבחון הבריאות אינן טוענות עוד את תיאור המשרה הארוך. לא נוספה קריאת תור נוספת בעת פתיחת בדיקה מונחית.

**מגבלה פתוחה:** בהרצת הענן `35079224207` נמצא כשל Browserbase עם HTTP 402. תוקנה בקשת יצירת הסשן, אך לא הוכח שהחשבון מאפשר כעת יצירת דפדפן. המפתח אינו זמין בסביבה המקומית, ולא הופעלה הגשה אמיתית לצורך הבדיקה. Gmail לא הוגדר באתר החי ולכן גם אימות דרך קבלות דוא״ל לא אומת מקצה לקצה.

## אמינות המקורות

- נוספה הבחנה בין רשימה מלאה לרשימה חלקית. Google ודפים רשמיים שלא הוכחה שלמותם אינם משמשים ראיה לסגירת משרות שלא הופיעו בתשובה. Workday ו־SmartRecruiters מסמנים חיתוך בגבול האיסוף או עמוד ריק מוקדם כאיסוף חלקי. תשובת HTTP מוצלחת שחסר בה מבנה רשימת המשרות אינה מפורשת כרשימה ריקה מאומתת.
- עמוד רשמי ריק או שלא חשף משרות אמינות משמר את הנתונים הקודמים. בריאותו אינה מוצגת כ־100%, והסריקה אינה נספרת כהצלחה מלאה.
- כרטיס המקור והדוח מבדילים בין ניסיון אחרון, הצלחה מלאה מאומתת, איסוף חלקי ומקור שלא אומת. נשמרת גם סיבת הדחייה.
- כותרות ניווט וקטעי HTML נדחים גם בלוח של משרה אחת. המתאם הכללי דורש נתוני `JobPosting` בעמוד, ולא מסתפק בקישור שכולל `career/job`. בדיקת מועמדים מוגבלת ל־40 עמודים, ללא Chromium. לוחות ייעודיים משתמשים במבנה שנבדק אצל המעסיק.
- תיאור קצר מ־200 תווים מסומן כחלקי ואינו מקבל דירוג המלצה גבוה כאילו היה תיאור מלא. אורכו אינו מוכיח לבדו איכות של תיאור ארוך יותר.
- מדינה/עיר מפורשות בנתונים המובנים קודמות לאזכור ישראל בתוך תיאור החברה. בפרט, חמש רשומות זרות של proteanTecs אינן מסומנות עוד כישראל רק בגלל הגדרת המקור.

## אימות

- הרצה מלאה ראשונה במהלך התיקונים: 854 עברו, 8 נכשלו. הכשלים תוקנו; לא הוחלשו דרישות אישור ההגשה.
- הרצה מלאה חוזרת: 870 עברו, ללא כישלונות או דילוגים.
- לאחר תיקוני המקורות הנוספים: 93 בדיקות מקורות/סורק/egress עברו; קודם לכן 76 בדיקות דפדפן ומקורות עברו, כולל שמונה תרחישי בדיקה מונחית/תור.
- בדיקות מסכמות אחרי הגנות הקצה האחרונות: **86 בדיקות הגשה** ו־**81 בדיקות מקורות ו־egress** עברו. [סיכום מכונה](repair-tests.json).
- ההרצה המלאה על הגרסה המשולבת: **877 עברו, 0 נכשלו, 0 דולגו**, כ־8:30 דקות. הגנות הקצה שנוספו בזמן ההרצה אומתו בנפרד ב־86 בדיקות ההגשה וב־81 בדיקות המקורות לעיל; תיקון ספירת הכותרות הפגומות אומת שוב ב־18 בדיקות איכות.

הבדיקות השתמשו במסדי SQLite זמניים. בדיקות כפתורי הצפייה השתמשו בספק דפדפן מדומה; אין בכך אישור לזמינות חשבון Browserbase. לא נבדקו Safari, Firefox, מכשירים פיזיים או עומס ייצור. מגבלות ה־egress והקריאות החיצוניות מפורטות ב־[מסמך התקציב](../SUPABASE_EGRESS.md). לא נוספו תלויות ייצור או מיגרציות מסד.

## תיקוני פרופיל ותצוגה במחשב נוסף

- זוהתה התנגשות בין הגבלת גובה הכפתורים במסכים נמוכים לבין אנימציית ההגדלה והכיתוב. בתפריט הקומפקטי בוטלה ההגדלה, הוקטנו האייקונים, והתווספה גלילה פנימית כשאין די גובה. שמות הפעולות זמינים לקוראי מסך ובכותרת ריחוף. התפריט הרגיל נשמר במסכים גבוהים.
- השרת מנרמל `ישראל`/`IL` ל־`Israel`. אחרי שמירה מוצלחת השדות שנשלחו מסתנכרנים לערך שהשרת החזיר, וכך המדינה אינה ממשיכה להופיע כלא שמורה. שינויים בכרטיסים אחרים והקלדה בזמן שהשמירה מתבצעת נשמרים כטיוטה.
- התראות פרטים חסרים ושינויים שלא נשמרו כוללות כעת קישורים לכל שדה. לחיצה פותחת את הלשונית והרובריקה, גוללת לשדה ומעבירה אליו את המיקוד. גם התראות הפרופיל במרכז ההתראות ובדיקת המוכנות בלוח הבקרה מפנות לשדה או להעלאת קורות החיים.
- שמונה בדיקות Chromium חדשות עברו: שמירת מדינה בשני המסלולים, שימור טיוטות לאחר רענון, פתיחת רובריקה סגורה ומיקוד, ארבעה גדלי מסך והקלדה בזמן שמירה. נבדקו חזותית צילומי מסך של מסלול תעשייה וניהול בגובה 720 ו־900 פיקסלים. המחשב הפיזי שממנו נשלחו התמונות לא נבדק ישירות.
- שינויי הממשק אינם מוסיפים polling או שאילתות מסד; ניווט ההתראות משתמש בטעינת הפרופיל הקיימת. לא נוספה תלות.

### אימות סופי לפני העלאה ל־Git

**889 בדיקות ייחודיות אומתו בהצלחה בשילוב ההרצות, ללא כשל או דילוג שנותר פתוח.** ההרצה המלאה כללה 885 הצלחות ושלושה כשלים בהגדרות הבדיקות החדשות/בדיקת CSS הישנה: כתובת API יחסית ללא base URL בשני מסלולי המקצוע, ופענוח בלוק CSS שתאם למבנה הישן. אלה תוקנו ואומתו מחדש. בהרצה הרחבה של הגרסה הסופית ללא בדיקות הסוכן עברו 790 בדיקות, ונכשלה רק בדיקת ה־CSS הישנה; לאחר עדכונה עברו כל 13 בדיקות החוזה. כל שמונה בדיקות הפרופיל החדשות עברו בנפרד, כולל בדיקת הקלדה בזמן שמירה שנוספה במהלך העבודה. 98 בדיקות הסוכן עברו בהרצה המלאה. פירוט ההרצות ב־`repair-tests.json`.

בנוסף עברו בדיקת תחביר JavaScript, בדיקת תחביר מודולי Python שהשתנו, `git diff --check`, ובדיקת דוחות ה־QA כנגד תבניות נפוצות של פרטי גישה. לא בוצעה הגשה אמיתית למעסיק ולא שונו נתוני הייצור לצורך הבדיקות.
