## תוצאה והיקף

מופו 260 רשומות מהדוח. בקוד נמצאו 259 מקורות מומלצים ייחודיים לאחר איחוד שלושת המסלולים; הרשומה הנוספת היא כתובת רפאל שהוגדרה כ-Ashby. נבחרו לחקירה 104 רשומות: 57 במצב לא מאומת, 31 ממתינות לאימות, 15 עם אפס משרות בישראל ומקור כושל אחד. כל 29 המקורות הכבויים כברירת מחדל ב-ZIP כלולים בחקירה. 156 המקורות האחרים מופו, אך לא עברו כאן ביקורת אתר פרטנית.

**זוהי חבילת תיקונים וביקורת, לא אישור שכל 104 המקורות שוחזרו.** לכל מועמד יש תוצאת בדיקה או ניסיון גישה מתועד. ב-45 מהאתרים לא התקבלה קריאה אמינה בכלי הגלישה; כשל כזה אינו אומר שהאתר נפל או שאין בו משרות. סומן במפורש מה תוקן, מה נשאר פתוח ומה כבר היה ממומש בקוד המקורי.

**אימות איסוף חי מתוך הקוד לא בוצע:** סביבת הרצת Python לא מצליחה להתחבר לרשת. כלי הגלישה כן אפשר לבדוק אתרים, קישורים ומשרות, אך הוא אינו אותה סביבת HTTP שבה פועל JobPilot. הבדיקות החדשות הן fixtures סינתטיים, לא הקלטות של תגובות API מהאתרים. לא בוצעה פריסה, גישה ל-Supabase, הפעלה של מקורות או שליחת מועמדויות.

## תיקוני רוחב במנגנוני האיסוף

**Ashby:** מזהה לוח נבדק לפני בקשת HTTP. כתובת board תקינה יכולה להפוך למזהה; כתובת רפאל או כתובת מתחזה נדחות. נוספה קריאה של כתובת המדינה והמיקומים המשניים, כדי שמשרה הזמינה גם בישראל לא תיעלם בגלל מיקום ראשי בחו״ל. נשמרים מזהים וקישורים תקינים; רשומות פגומות אינן הופכות להוכחת היעדר משרות. מודעות המסומנות isListed=false לא נאספות.

**Workday ו-SmartRecruiters:** כשל בהורדת דף פרט, JSON פגום או תיאור ריק אינם חוזרים עוד כמשרה עם תיאור חסר. מזהים שנחסמו נשמרים באבחון והתוצאה מסומנת חלקית. נוספו בדיקות סכימה, מונה תוצאות, עמודים חוזרים וזהויות כפולות. ב-SmartRecruiters כתובת דף הפרט נבנית בנתיב ה-API הנתמך במקום לעקוב אחר row.ref שרירותי.

**שמירת נתונים וזהויות:** ה-wrapper של official_careers אינו מאבד blocked_external_ids של הקורא הפנימי. ניתובים ששונו מוחזרים כתשובה חלקית כדי שלא לסגור משרות ישנות רק משום שהכתובות/המזהים השתנו. אין מחיקת היסטוריה או שיוך אוטומטי לחברת אם. ייתכנו כפילויות זמניות או משרות ישנות בעקבות מעבר ATS; איחוד שלהן דורש reconciliation נפרד ומאומת. מדיניות ההתיישנות הקיימת במוצר לא שונתה.

**תקציב משאבים:** לא נוספו מקורות פעילים כברירת מחדל, ולא שונו איחוד המסלולים, הדירוג או הסריקה המתוזמנת. סקריפט האבחון אינו מייבא את מסד הנתונים ואינו קורא משרות מ-Supabase. ניתוב Flex/Cadence מוגבל לעד 43 בקשות למעסיק לכל מקור; אסם/Elspec לעד 41 בקשות, כל תגובה עד 4MB ועד 40 דפי פרט. מגבלות ישנות של קוראים אחרים לא נכתבו מחדש: לא לכל collector יש מגבלת בתים ב-streaming. ההרחבות ותקציב כלי התיקון מתועדים ב-docs/SUPABASE_EGRESS.md.

## התקנה ואימות בסביבה שלך

העדכון אינו דורש מיגרציית נתונים או תלויות Python חדשות. ה-ZIP המלא הוא עותק קוד נקי, ללא .env, בסיס נתונים או קבצי משתמש. יש להחיל על עותק מגובה של הפרויקט, ולא להחליף או למחוק את תיקיות הנתונים המקומיות.

חלופה נוחה היא ה-patch המצורף, מתוך שורש JobPilot. יש לשים את הקובץ בשורש הפרויקט או להתאים את הנתיב. git apply --check חייב לעבור לפני החלה; אין להשתמש ב-force או לדרוס עבודה מקומית במקרה של התנגשות.

```bash
git status --short
git apply --check jobpilot-source-audit-20260926.patch
git apply jobpilot-source-audit-20260926.patch
```

הרצת בדיקות המקורות, בסביבת ה-venv הקיימת:

```bash
python -m pytest -q tests/test_source_audit_20260926.py tests/test_source_recovery.py tests/test_collector_completeness.py
```

בדיקת שמונת היעדים ששונו/נוספו, ללא גישה ל-DB, ללא שמירת משרות וללא הפעלת מקורות:

```bash
python scripts/audit_source_health.py
```

הפקודה מייצרת source-health-live.json. היא בודקת Moon Active, Nova, Wiliot, Flex, Cadence, Arbe, אסם־נסטלה ו-Elspec. תוצאה partial אינה אישור שהלוח נסרק בשלמותו; verified_empty_payload מעיד רק על תשובה מובנית ריקה של ה-API, לא על כל ערוצי הגיוס של החברה. יש לבדוק מספר משרות בישראל, שלמות תיאור, זהויות וקישורי הגשה. הפעלת מקורות כבויים או שינוי production ייעשו רק לאחר אימות התוכן הזה.

לבדיקת כל 104 המועמדים, עדיין ללא מסד נתונים וללא הגשות:

```bash
python scripts/audit_source_health.py --all-flagged --output source-health-live-all.json
```

תיקון הכפילות של רפאל הוא כלי נפרד, שיש להריץ רק מול מסד הנתונים המיועד. פקודת ברירת המחדל מציגה תכנית ללא שינוי:

```bash
python scripts/repair_source_audit.py
```

רק אחרי גיבוי ובדיקת התכנית, כשמופיעה הפעולה retire_invalid_ashby_duplicate עם מקור רשמי תואם:

```bash
python scripts/repair_source_audit.py --apply
```

הכלי קורא לכל היותר 51 רשומות Source עם הקרנת שדות ו-metadata תחום; הוא מסרב לשנות מעל 50 רשומות או כאשר metadata חורג מהגבול. לא נקראות טבלאות Job, לא נמחקת אף משרה ולא משתנים מזהים קנוניים. אם אין בדיוק מקור רפאל רשמי פעיל באותו קטלוג/משתמש, הפעולה נשארת needs_review והכפילות אינה משתנה. פרישת הכפילות אינה פותרת את חסימת אתר רפאל עצמו.

לאחר אימות מקומי והפריסה הרגילה שלך, פקודות Git לשמירת התיקונים בלבד מפורטות בקובץ APPLY_SOURCE_AUDIT.md. לא בוצעו commit או push במסגרת הבדיקה.
