JobPilot v0.1.4 — Test Report
Generated: 2026-08-04

Implemented
===========
1. Permanent job deletion from every job card and from the rich job-details dialog.
2. Deleting a job also deletes its related Application and Blocker records.
3. Scanned jobs are stored only when their location explicitly matches Israel or a known Israeli city.
4. Ambiguous locations such as Remote, Worldwide and EMEA are rejected.
5. Legacy foreign jobs are permanently purged on the first server startup after the update.
6. Manual imports with a foreign or ambiguous location return HTTP 400.
7. Scan reports distinguish raw collected jobs, Israel jobs and foreign jobs filtered out.

- 55 tests passed.

- A new real-Chromium offline UI test passed and verified both delete buttons, confirmation dialogs, DOM refresh and the Israel-only scan report.
- Python compileall passed for app, agent and tests.
- `node --check app/static/app.js` passed.

Location-filter coverage
========================
Accepted examples include:
- Israel / Remote - Israel
- Tel Aviv / Haifa / Jerusalem / Herzliya / Ramat Gan
- Petah Tikva / Ra'anana / Rishon LeZion / Yokneam / Beer Sheva
- Hebrew forms such as תל אביב, חיפה, פתח תקווה and קריית גת

Rejected examples include:
- Empty location
- Remote / Worldwide Remote / EMEA
- London / New York / Chicago, IL / Paris / Berlin / Toronto / Sydney / Dubai / Singapore
