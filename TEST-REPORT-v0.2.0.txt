JobPilot v0.2.0 — Professional Tracks Test Report
Generated: 2026-08-11

Scope
=====
This release introduces first-class professional search tracks. The current build
contains Computer Science (CS) and Industrial Engineering & Management (IEM), with
a generic track registry/schema intended to support additional professions later.

Track isolation
===============
Verified as separate per track:
- skills and skill suggestions
- desired titles
- positive and excluded keywords
- experience settings/options
- salary expectation
- preferred locations and work modes
- auto-queue threshold and enabled state
- selected CV path and resume versions
- source rows, enabled/error state and source health
- collected jobs, scores and recommendations
- applications and blockers through their associated job
- dashboard metrics and source-error badge
- browser-local profile drafts

Shared intentionally across tracks:
- identity/contact information
- work authorization and sponsorship
- reusable application-question answers
- extended application identity/profile fields

Search-agent safety
===================
- Exactly one professional track is active at a time.
- The inactive track is explicitly shown as "search agent off" in the switcher.
- Scanner entry rejects an inactive track before invoking any collector.
- A single global scan lock prevents parallel cross-track scans.
- Track switching is rejected while a scan is running.
- Scheduled scanning always resolves the currently active track.
- Agent task claiming filters queued applications to the currently active track.

IEM product configuration
=========================
- Dedicated yellow/gold light theme.
- Dedicated warm yellow/gold dark theme.
- IEM job families include industrial engineering, business/data/BI analysis,
  operations, supply chain, planning, procurement, logistics, PMO/project/program
  management, process improvement, operational excellence, manufacturing,
  quality and NPI.
- IEM skills include Excel, SQL, Power BI, Tableau, ERP, SAP, Priority, Lean,
  Six Sigma, process improvement, project management, supply chain, procurement,
  production planning, operations research, statistics, Power Query, VBA and Python.
- 22 IEM recommended source rows are installed independently from the 42 CS source rows.
- IEM matching applies an additional professional-relevance gate so broad company
  boards do not flood the track with unrelated software roles.

Agent-browser suite limitation
==============================

flow tests. Agent track isolation is therefore covered at the API/database task-claim
layer in this build, including a test that a queued IEM task is claimable while a queued
CS task stays untouched when IEM is active.
